# AB-090: curated child learning, strictly no live input (partial)

This page provides a small static, neutral civic-literacy FAQ for visitors of all ages, with native accessible details/summary interactions and ordinary links to already published public bills. It neither starts an account/session nor requests a microphone, personal question, parental identity, third-party analytics or an LLM. No voice or animated Bill model is necessary.

The user can read basic definitions and learn that proposed bills, enacted laws and currently effective laws are different. It does not present specific policy advocacy, legal advice or a verified legal status claim. Under-13 free input remains **disabled**. The parent-initiated verifiable-consent adapter and real provider-specific safeguards in the full AB-090 plan have not been implemented or claimed.

Node HTTP tests verify that requesting `/learn` triggers no publication lookup or provider and returns a no-script CSP/no-set-cookie page. This is partial AB-090; full parental consent, content review, mobile/real accessibility audit, localized tours and voice remain outstanding. Rollback removes static learning endpoint only.
