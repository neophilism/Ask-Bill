# Ask Bill publisher administration

The production publisher login and admin interface are **not yet enabled**. This directory marks the deliberately reserved private/admin route, which will be implemented only after an authenticated provider, MFA, role-scoped database access, CSRF/browser tests and negative security cases are accepted.

The AB-008 fixture authorization adapter must never be exposed as a public login service. Public legislative reading requires no account or authorization. No unrelated company's credentials, accounts or APIs are permitted here.
