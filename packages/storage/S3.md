# Private S3-compatible source storage

`createS3PrivateStorage` in `s3.mjs` takes a trusted HTTPS `endpoint`, `region`,
`publisherId`, private `bucket`, credentials and optional separate
`quarantineBucket`/`sourceBucket`. It uses path-style requests by default;
set `pathStyle: false` only for providers supporting virtual-host bucket names.
No credential or private source byte is placed in public reader configuration.

The returned methods are `putQuarantine`, `getQuarantine`,
`promoteQuarantine`, `putPrivateSource`, `getPrivateSource`,
`deleteQuarantine` and `signedDownload`. All require the configured publisher
UUID and an exact SHA-256 digest. Metadata keys are
`publisherUUID/sha256/digest`; remote object paths prefix that key with
`quarantine/` or `private-source/`. These namespaces remain private even when
they share one private bucket. No public-pack operation or guessed key lookup
is exposed by this adapter.

Uploads first pass the document scanner and the 25 MiB limit. Requests sign
the actual payload SHA-256 with AWS Signature Version 4 and send an independent
SHA-256 checksum plus `If-None-Match: *`. A collision is accepted as an
idempotent retry only after the existing object matches the expected bytes,
digest and MIME. Every successful write is followed by a bounded GET whose
actual content is hashed before a verified receipt is returned. Redirects are
blocked, so a provider response cannot forward credentials to another host.

`signedDownload({scope,publisherId,sha256,key,ttlSeconds})` signs only an exact
private object. The default lifetime is sixty seconds and the maximum is five
minutes. It requests attachment disposition and private/no-store caching.
This URL is a temporary bearer capability and can be replayed until expiration;
it is not a public asset address or a one-use token. The publisher server must
authorize the requester before issuing it. Publisher uploads currently pass
through the authenticated bounded server route, so untrusted browsers never
receive S3 write credentials.

Use a private bucket with public access blocked, narrowly scoped credentials,
transport and at-rest encryption, and a quarantine expiration policy matching
the deployment's actual retention decision. Promotion preserves the private
original. Quarantine cleanup does not delete the preserved source. The adapter
does not create buckets, change their ACLs or assert that operator settings were
verified.

`tests/s3-provider.test.mjs` reproduces the official AWS SigV4 GET example and
checks actual checksum/signing behavior against a local injected S3 fixture.
It also covers source promotion, immutable retries, cross-publisher/key/MIME
attacks, corrupt reads, redirect rejection and bounded signed downloads.
Production activation requires a separate credentialed upload/read/promote/
download/expiry exercise against the selected private store.
