# AB-089 source-only guided reading tour — partial

As a reader, a visitor can follow a simple ordered tour of exact provisions from one fully published version. The native HTML page requires no account, JavaScript, graphics, speech, AI provider, or supplied Bill model. Each step contains an exact excerpt and hash and links directly to the full authoritative provision so exceptions are not silently omitted. If a document is long, the tour is visibly labeled as a partial introduction. Visitors may leave/resume through stable version-pinned links.

The tour does not generate a policy summary, claimed benefits, audience analysis, or objections, since those require genuine source review and attribution. No personal chat or audio is stored. Full curated thematic tours, interruption-return orchestration and voice/animation remain additional acceptance work after the original Bill assets and speech are available.

Run `node --test tests/source-tour.test.mjs`, and verify full GitHub quality, browser, PDF and PostgreSQL checks before merging. Rollback removes the optional tour route/link and leaves published sources unchanged.
