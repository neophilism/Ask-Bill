# AB-074 — Graphics resource quality tiers and lifecycle (partial)

Implements a deterministic renderer-agnostic quality governor under `packages/character/quality/governor.mjs`, plus an allowlisted manifest LOD selector. Resource and frame budgets are based on the approved architecture: medium 35k triangles, low 12k, high 70k, mobile 30fps, desktop 60fps. The controller conservatively downgrades on sustained slow frames, memory pressure and data-saver; it suspends on hidden tab/context loss, requires an explicit verified renderer reload to resume, forbids silent upgrades and returns a source-only poster fallback when no safe LOD exists.

Local Node v22.16.0 `node --check packages/character/quality/governor.mjs && node --test tests/graphics-governor.test.mjs` passed 10 cases. This does not measure real GPU performance, perform glTF decoding, prove accurate texture budgets or implement the Three.js renderer; those need browser/physical-device validation and AB-063/064/069/073 integration. It does not grant release acceptance of Bill's candidate GLBs.

Rollback disables adaptive governor, keeps the simple poster/source-reader fallback, and never discards canonical legislative text.
