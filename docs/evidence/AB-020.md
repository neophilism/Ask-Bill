# AB-020 — Congress.gov official metadata adapter (partial)

Implements a server-only exact bill and text-version API adapter with HTTP header credentials, 304/ETag handling, bounded JSON streaming, fail-closed official-source URL validation, finite retries and rate guard. Structural metadata does not infer enactment or authoritative text contents. Source IDs remain version-specific SHA-256 hashes.

Verification: node --test tests/congress.test.mjs, pin Node 24 and run current GitHub quality, browser, database and PDF checks. Unit tests use a mock response; real congressional data/credentials and full source ingestion, distributed quotas and stale/publisher presentation are pending. No third-party company integration. Rollback: disable the isolated metadata adapter, keep the prior verified source pack.
