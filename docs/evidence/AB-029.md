# AB-029 — source-permissioned question routing (partial)

An independently owned server-only routing contract pins every question to a trusted publisher and exact selected bill version, consults a server-side version resolver before allowing any read tool, and distinguishes bill explanation, current law, prediction, hypothetical, attributed position, personal legal application, and explicitly hostile tool requests. The output exposes only a question digest and minimum metadata, never a raw question string for logs. An unknown or under-13 age band is restricted to curated routes by default. Personal application and unsupported current-law requests have no provider tool scope.

Verification: 8 negative and behavioral Node tests, including forged publisher/version IDs, under-13 restrictions, private previews, malformed/oversized prompts and forged selections. All existing pinned workspace plus Chromium, PostgreSQL and PDF checks must pass on the exact head before merging.

This is NOT a live LLM/chat provider, actual parental consent service, independently verified current-law source corpus, authentication bypass or functioning publishing UI. Live free-text/voice remain disabled until future stages. Resolver must be a trusted server-side database lookup; do not take publisher/corpus permissions from user input or a model. Rollback by disabling live routing and displaying source-only curated explanations.
