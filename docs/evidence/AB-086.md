# AB-086 — Conversation epochs and cross-modal interruption (partial)

Adds a deterministic scope coordinator that cancels generation, audio, captions, animation and microphone together on a new question, source-version switch, stop or disposal. Fences asynchronous completions by answer, source version and monotonically increasing epoch, keeps only limited non-content diagnostic status, and deliberately does not emit model answer text or automatically authorize legal claims/citations. The upstream server must run AB-035/036 independent source verification before rendering anything.

These tests use mock component adapters and do not certify actual device microphone, streaming server cancellation, WebAudio crossfade or the final 3D Bill in a browser. This is a **partial AB-086**, not completed voice acceptance. Live provider rights and safety remain disabled.
