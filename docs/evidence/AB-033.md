# AB-033 — conservative semantic support and exception-preservation gate

The initial deterministic evaluator accepts only an **exact verbatim quotation** whose entire displayed text matches one verified source span, with source hashes recomputed. General explanatory paraphrases, predictions, unattributed advocacy, unsupported or out-of-version claims and all detected unresolved references or truncated retrieval remain `needs_semantic_review`, not displayable. Where an exception marker exists, every affected source must be fully quoted to prevent omission of material qualifications.

A permitted literal result has `entailmentMethod: exact_verbatim`, `displayAllowed: true` only as a visibly labeled source quotation, `spokenAllowed: false`, `supportsLegalInterpretation: false`, and immutable verified claims; the runtime is not a legal advisor or a general model evaluator. General LLM paraphrases still need independent semantic entailment checks, source status and user-facing accessibility work before release.

Seven unit/security tests cover literal quote promotion, fabricated 'always legally binding' paraphrases, decisive omitted exceptions, unresolved source references, stale/tampered SHA-256 citations, child/private scopes and hypothetical/interpretation claims. Run exact-head CI and separate source review before merge.

**Partial operational acceptance:** no real provider/held-out semantic classifier, no full official legislative corpus evaluation, and no production answer display endpoint. Rollback: disable literal promotion and retain all generated text on the AB-032 review hold.
