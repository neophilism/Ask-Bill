# AB-039 Attributed objections, disputed positions and explicit unknowns — partial

Deterministic source cards separate exact legislation from attributed public positions. Statutory wording has source/version SHA-256 and Unicode span proof; supporter, opponent, concern and neutral statements require their **own** dated and hash-matched public statement record. The UI-facing data labels both source types distinctly and never manufactures a viewpoint merely to make a balanced pair. Missing citations, ambiguous text or unsupported predictions produce explicit unknown or estimate labels, not fabricated certainty.

The source URL allowlist is HTTPS-only but a URL alone does not establish authenticity; a future trusted publisher/provenance adapter must import original statement bytes. This PR does not source real advocacy, compare an actual bill, give legal advice, activate AI/voice or launch a user-facing application. Adversarial tests cover fabricated text, tampered hashes, unsupported forecasts and HTML escaping. No external company code or credential dependencies.
