# AB-082 — Audio-clock transport (partial implementation)

Scope: independent Ask Bill browser AudioContext transport in `packages/voice/playback/controller.mjs`. It is a **partial** AB-082 milestone: the public app still has no selected/licensed TTS provider, generated speech, actual audio delivery, or integrated React controls.

No playback begins until an explicit user gesture. `load` only takes a decoded, bounded in-memory `AudioBuffer` and metadata whose source-validation and voice-license flags have been checked by the *trusted calling service*. Those flags are client hints, **not cryptographic authorization**, and an authenticated server must independently validate text, rights, audio digest and version. This module makes no external HTTP call and starts no microphone, recording, account lookup or analytics. The existing fail-closed TTS adapter remains disabled until licensing, provider and retention checks pass.

Functionality: pause/resume/stop/replay, adjustable rate 0.75–1.5x, output mute without removing text, cancellation on hidden tabs, source-version and conversation-epoch fencing, stale/late `onended` rejection, no implicit auto-resume, and idempotent resource cleanup. The app must bind `visibilitychange`, document switches and stop/cancel input to these methods when it integrates the player. Text/captions remain the authoritative output.

Security and accessibility: bounded audio duration and channels, exact document/epoch scope before every play; no arbitrary audio URL or JavaScript callback taken from model output; only in-memory sanitized state notifications; inaccessible AudioContext fails cleanly to text. No selected voice provider was verified. All untrusted audio must be decoded after server-side licence/source/integrity validation.

Local regression evidence: `node --check packages/voice/playback/controller.mjs` and `node --test tests/playback.test.mjs` on Node 22.16.0: eight subtests passed, including stale epoch, hidden tab, user-gesture, invalid clip and a delayed-resume cancellation race. **GitHub head-bound CI, real Chromium/WebAudio gesture test, Safari/iOS playback, external voice licensing and live provider delivery remain unverified** until tested on their exact accepted versions.

Rollback: remove the isolated playback controller and export, disable audio controls; retain validated text and captions without playback.
