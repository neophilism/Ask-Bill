# AB-024 Immutable, review-gated release packs — partial delivery

`planReviewedRelease` checks independent source object hash provenance, complete version text, completed activated index, explicit six-part review record, reviewer and trusted MFA context, and staged public-pack byte integrity. It computes an immutable release digest but **never** publishes as a result of an in-memory approval marker. Source-only reading remains available if staging fails.

The PostgreSQL migration adds publisher-scoped immutable release manifests and a single transactionally updated publication pointer, with an outbox event written atomically. Activation functions must be called only by a dedicated authorized publisher backend role after authentication/MFA and external object verification. A database migration/role in isolation does not constitute production publisher login or authentic object-store transfer.

Pending full acceptance: genuine identity/MFA provider, real reviewed source from a complete bill, external object-store upload, status cache invalidation, rollback/withdrawal testing and full staging API/UI work. This PR is a verified foundation, not a production release or complete AB-024 gate.
