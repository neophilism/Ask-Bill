# AB-083 — Audio-clock viseme morphology (partial)

This addition maps the nine AB-081 speech timing labels onto the **actual GLB mouth morph target names** used by Ask Bill's generated character roster (`viseme_AA`, `viseme_EE`, `viseme_OH`, `viseme_OO`, `viseme_MBP`, `viseme_FV`, `viseme_L`, `viseme_SS`, `viseme_sil`). The generated GLBs contain a `MouthVisemes` mesh even though the top-level character manifest separately lists only body morphs. The full character still requires visual/functional approval and editable-source acceptance.

The `createLipSyncDirector` scheduler operates only on independently validated, version-pinned AB-081 timing envelopes, using caller-supplied **actual audio playback time**. Its deterministic in-memory frames smooth phoneme edges, normalize mouth weights, and identify the `Talk` clip and exclusive morph mask. It never guesses phonemes from an LLM answer. Missing morph targets, no verified alignment, hidden tabs, paused audio, reduced motion and cancellations fall back to a neutral closed mouth. Wrong document versions and epochs fail closed. It has no access to audio provider credentials, private user questions, microphone, DOM or network.

The `Talk` GLB clip itself contains weight animations. The final AB-064 animation mixer **must mask/remove those GLB mouth-weight tracks** when AB-083 owns mouth morphs, otherwise two controllers will conflict. This PR does not implement that mixer or runtime Three.js rendering, does not authorize audio delivery, and does not claim a 100 ms lip-sync measurement without live audio/browser testing. Any visible mouth motion must still respect source-validation, licensing and user-gesture policy.

Local evidence: Node 22.16.0 `node --check packages/voice/lipsync/index.mjs` and `node --test tests/lipsync.test.mjs`: eight deterministic tests passed covering phoneme mapping, normalized weights, coarticulation, missing meshes, silence, motion preference, late events and source-integrity errors. Hosted CI, real GLB morph binding and WebAudio clock-driven browser measurements remain pending.
