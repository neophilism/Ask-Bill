# AB-075 — Bill pause/hide/reduced-motion controls (partial)

This module bridges accessible browser controls to the deterministic AB-071 performance director without modifying source text, stealing keyboard focus or intercepting native scrolling/selection. `Pause Bill`, `Hide Bill`, and `Reduce Bill motion` are independent, keyboard-operable buttons with `aria-pressed` state and clear reversible labels.

The controller honors the OS `prefers-reduced-motion` setting immediately and does not let a user toggle bypass an active system motion-reduction preference. Hidden-tab state is separate from the user's Hide Bill choice; restoring a tab does not silently resume animations. Pointer, keyboard, selection, touch, focus and scroll activity immediately cancels movement. Anonymous preferences are intentionally **session-local only**—there is no account profile, tracking, microphone, camera, background analytics or persistence of reading interests.

This is **partial AB-075**: it provides an isolated trusted browser adapter and event model, not final integrated Next.js/Three reader controls, accessibility certification, full mobile focus/keyboard coverage or persistent preference UX. Bill's motion and the underlying legal text remain separate; users can read and cite legislation even with the character hidden or renderer unavailable.

Node 22.16.0 evidence: `node --check packages/character/preferences/motion.mjs` and `node --test tests/character-motion-preferences.test.mjs` — six tests passed, including system/user preference precedence, tab restore, controls' pressed state and event unbinding, and invalid input rejection. Exact-head GitHub CI, real browser voiceover/keyboard checks and cross-device layout verification remain outstanding.

Rollback: remove the optional motion-control adapter and default Bill to a static dock; source-only reading remains functional.
