# AB-004: accessible reader shell — partial implementation checkpoint

Repository: `neophilism/Ask-Bill`. Work branch `ab-004-reader-preview` depends on AB-003 / PR #3, AB-002 / PR #2, and AB-001 / PR #1.

## Implemented
A local, accessible HTML reading preview served from Node's built-in HTTP server. Features: exact incomplete draft fixture, strong source-status warning, semantic document headings, quick source disclosure, optional sample-question answers grounded in the fixture, readable source card, keyboard-friendly question/text-size/illustration controls, static Folio placeholder, responsive layout, skip link and reduced-motion stylesheet. No secrets or external services. `pnpm preview` binds to localhost by default.

## Actual offline tests
Node 22.16.0: `node --check apps/web/preview/reader.mjs`, `node --check apps/web/preview/preview.js`, `node --check apps/web/preview/server.mjs` and `node --test tests/preview.test.mjs` — 3/3 tests pass. Tests cover status fail-closed checks, escaping an adversarial excerpt, exact source rendering, CSP, restricted routes, health signal, invalid methods and local HTTP behavior. Source Git blob IDs match the exact locally exercised code.

## Outstanding acceptance
This is a **partial AB-004 delivery**, not final acceptance: the approved architecture still requires the Next.js/React web shell, browser-level keyboard/axe audit, responsive 320-pixel screenshot evidence, browser with JS disabled, and browser SR verification. The preview does **not** implement 3D Bill, lip sync, real live AI, TTS, publisher workflow, full official source packs, production deployment or domain. Current-head CircleCI checks are not yet reported; do not merge this branch until the prerequisite chain and required real checks pass.

## Rollback
Disable the localhost preview command or revert this PR. The source registry, contracts and backend packages are unaffected.
