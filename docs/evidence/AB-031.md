# AB-031 — verified lexical and dependent-source retrieval

Adds an independently owned source-evidence retrieval module that requires a server-approved, published tenant/version route from AB-029; an immutable source-bound index generation from AB-023; and the versioned definitions/exceptions/reference graph from AB-019. Every resulting source is matched against its original text SHA-256 from the active index. The retrieval budget is bounded, and unresolved references, decisive exception markers and truncation are explicitly returned rather than silently ignored. Normalized lexical matches are never reused as Unicode citation offsets.

Seven tests cover tenant/version/prompt mismatch, tampered source bytes, controlling exceptions, missing references, bounded expansion, search misses and deterministic output.

**Not full acceptance:** no vector retrieval benchmark, official complete-bill source pack, live answer generator or end-to-end validator. Future AB-032/033 must verify entailment and exception completeness. Source-only and incomplete results remain safe when live AI is unavailable. No source is published or external provider called.

Rollback: disable derived expanded evidence and preserve exact original bill/provision source access.
