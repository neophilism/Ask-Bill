# AB-042 Public source-only cache, budgets and provider fallback — partial

Implements a process-local, bounded cache that accepts only source-verified AB-035 issued `segment.validated` events for public complete legislation and nonpersonal bill-explanation categories. It rejects self-asserted approval flags, incomplete/private or personal routes, unsupported claim types, wrong versions and arbitrary model fields. Cache keys include publisher, exact version, question fingerprint, source/canonical digest, model, prompt, retrieval, validator and locale hashes. Any version/source/validator change invalidates the key. No raw question content, session cookies, child activity or publisher drafts enter shared cache.

Provider outages, quota ceilings and circuit breaks degrade to still-readable **published source text and curated approved cards**, not cached private content or speculative answers. The circuit breaker enforces a cooldown with one permitted half-open probe.

Four adversarial/unit tests cover server-issued approvals, personal/private denial, version/config invalidation, expiry/purge and fallback behavior. **Pending:** distributed cache with atomic invalidation, authenticated source origin, actual global spend reconciliation and live provider/circuit staging tests. The module alone is not full AB-042 operational acceptance. No character or unrelated product dependency.
