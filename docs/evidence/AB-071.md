# AB-071 — Deterministic source-semantic character director (partial)

The new `packages/character/performance/director.mjs` takes independently verified answer-stream events and coordinates the selected Bill's stage in a bounded state machine: thinking, navigating, explaining, docked, paused and hidden. It accepts the four approved semantic cue types, validates version/epoch/sequence and references only claims/sections registered from preceding validated segments. All motion clip outputs come from a closed allowlist (`Point`, `Explain`, `Shrug`, `Nod`). Neither an LLM nor a source document may supply DOM selectors, CSS, URLs, coordinates, speed or arbitrary animation names.

The caller provides a **trusted local layout resolution function** which maps an approved source `provisionId` to its *current* measured surface and returns a safe/visible state. The director never scrolls automatically; offscreen, unsafe or missing targets return source-preview/docked instructions. Focus, selection, scroll, question, speech, pointer, touch, keyboard and pause events interrupt motion immediately. Async target lookups are fenced with AbortController, operation token and immutable document/epoch identity; late results cannot revive an old answer. Renderer exceptions are isolated so source reading survives graphics failure.

This is partial AB-071, not the full production Three.js performance director. Existing AB-064 animation-mixer and AB-070 gaze/point calibration dependencies are not yet accepted; the director's commands will require safe browser stage integration and visual QA. No emitted semantic cue is source authority on its own: the actual application must feed events from its independent AB-035/036 verifier and a trusted browser layout registry. No live microphone, audio, AI keys or full 3D rendering is introduced.

Local evidence: `node --check packages/character/performance/director.mjs` and `node --test tests/performance-director.test.mjs` under Node 22.16.0: 9/9 passing. An initial hidden-to-paused transition defect and invalid-sequence mutation bug were fixed before the PR. Hosted exact-head CI, real Chromium focus/selection tests and mobile path safety tests remain to be run.
