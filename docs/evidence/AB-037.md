# AB-037 — Dated primary-law comparison (partial)

Separate official primary-law records from proposed bills, version IDs, source-byte hashes and effective/as-of dates. Exact Unicode spans prevent a draft's description of current law from becoming an asserted fact. Initial allowed federal primary sources are US Code and GovInfo HTTPS endpoints. Arbitrary user-supplied URLs are not fetched.

The result is explicitly a *dated source-text comparison*, **not** a computed amendment, verified enacted-law effect, legal interpretation, or personal advice. A source-origin host allowlist and integrity digest do not by themselves prove an authentic official retrieval; the published source adapter must bind verified bytes to the official retrieval response.

Outstanding: signed provenance/real staging import, authenticated primary-source retrieval and current-as-of confirmation, full jurisdiction coverage, user interface and provider evaluation. No user character asset, new credentials or unrelated service integration is required. Failing source verification disables current-law comparison while preserving draft reading.
