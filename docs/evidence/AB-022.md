# AB-022 — source-bound proposed amendment and computed comparison previews

Implements deterministic Unicode code-point edits for insert, strike, replace, repeal and redesignation, preserving the original source with version-specific text and SHA256 spans. Every computed result is explicitly nonauthoritative and publication-disabled; malformed, ambiguous, overlapping or stale instructions return structured blocking conflicts instead of an approved combined bill. Redesignated clauses carry old and computed IDs. No current-law or enacted-status inference is permitted.

Tests: source quote hash tampering, Unicode mutation, disjoint operation ordering, overlap/structural conflict, repeal, redesignation, version rejection and computed-only output. Exact-head Node quality, browser, PostgreSQL and PDF CI required before merge. The runtime does not yet implement publisher-facing correction UI, real House/Senate amendment syntax mapping, cross-version lineage or human-source verification; full AB-022 operational acceptance remains incomplete.

Rollback: disable computed comparisons and retain the original bill versions and their exact source URLs.
