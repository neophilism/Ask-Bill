# AB-085 — Strictly opt-in push-to-talk, transcript review (partial)

Adds a browser-controlled, provider-neutral microphone admission/recording/transcript state machine in `packages/voice/stt/push-to-talk.mjs`. It never starts capture without an explicit user gesture, adult gate, known source version/epoch, and an **enabled verified provider policy**. The production default remains disabled, so no microphone prompt or audio collection occurs until genuine provider/privacy authorization is completed on the server. The module itself performs no network requests or persistent storage; injected transcriber is a trusted caller responsibility and is usable for tests only until providers are approved.

User must separately request transcription after stopping, can edit recognized text, and must explicitly submit; returned transcript submission is **not authorized to reach the AI automatically**. Recording and transcript references are discarded on cancellation, stale version, permission failure and disposal. Typed entry remains available. A microphone permission prompt and a self-declared adult flag do not constitute verified parental consent; child live input stays disabled.
