## Security and rollback

Secrets are read only in manually dispatched jobs. No key is stored in code, checkpoint, GitHub public CI, asset manifest or URL. Paid-task resubmission requires prior checkpoint restoration or explicit reconciliation. Produced artifacts on a public GitHub repo must be treated as potentially public; runtime deployment is separate. Roll back by disabling/removing the manual workflow and tools, leaving Ask Bill's source reading and 20 experimental characters untouched.
