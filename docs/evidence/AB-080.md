# AB-080 — guarded speech preflight (partial)

Dependency foundation AB-009, AB-030, AB-032, AB-034 and AB-079 is represented on merged main. This unit adds source-verifying preflight for approved *verbatim* legal text and rejects private/incomplete/wrong-version sources, forged quotes, unreviewed model drafts, aborted requests, budget overruns and bad audio candidate metadata.

No external voice rights/provider/credentials are supplied. Both \`synthesize\` and \`deliver\` fail closed. No audio is published and no streaming speech event is enabled.

Acceptance pending: independently licensed original voice identity, backend synthesis adapter, authenticated audio references, durable quota/reservation settlement, real provider cancellation/byte/timing checks, and privacy tests. Strict source verification is necessary but not itself proof of semantic interpretation accuracy.

Validation: Node 24 GitHub quality / browser / PDF / PostgreSQL CI against PR head and \`node --test tests/tts-gate.test.mjs\` must pass before a scoped merge. Rollback removes the self-contained optional module.
