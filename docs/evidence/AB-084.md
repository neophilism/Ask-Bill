# AB-084 — Text-first captions and transcript (partial)

This independent Ask Bill presentation module provides keyboard-readable HTML and plain-text captions for validated, exact-source answer events. It does not produce or fetch audio and remains useful when Bill is hidden, muted, graphics fail, or a TTS provider is unavailable.

The `packages/ui/captions/index.mjs` transcript model enforces version, answer, sequence and epoch fencing; one-time segment announcements (rather than streamed token announcements); exact quotation claim semantics; source anchor links; explicit correction labeling; fail-safe cancellation/failure; and bounded in-memory history. It never uses `innerHTML`, URLs from a model, untrusted scripts, browser storage or raw personal question logs. HTML is escaped and text is selectable.

**Important trust boundary:** input events must first pass the existing cryptographic source verification and validated-stream controllers (AB-035/036); structural `claim.kind='bill_text'` tags alone do not prove legal accuracy or source authority. This is a presentation adapter, **not** an independent legal validator. No production transcript page, screen-reader audit, TTS license or live voice source is claimed finished.

Local evidence: `node --check packages/ui/captions/index.mjs` and `node --test tests/captions.test.mjs`: 8 tests passed under Node 22.16.0, exercising source/version fences, replay, corrections, muted captions, malicious markup, size limits and late events. Current-head GitHub CI and browser assistive-technology verification remain necessary.

Rollback: fall back to existing complete-source reader and citation drawer; the accessibility path remains available without voice.
