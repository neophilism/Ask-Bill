# AB-035 Validated streaming (partial)
Independent Ask Bill event-only SSE buffering and replay, without raw model tokens. It rejects wrong versions, stale epochs, unapproved source segments, duplicate segments, unknown citation targets and late events. Replay is bounded; partial history expires.
**Not production ready:** the in-memory event buffer is not a durable multi-instance API; provider approvals must be tied to actual authenticated grounding evidence, rather than a caller-supplied boolean. Server endpoints, secure session integration, SSE reconnect and live browser/provider tests remain required. This PR is stacked on AB-034 and cannot merge until its prerequisite gates pass.
