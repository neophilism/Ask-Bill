# AB-040 — Version-pinned synthetic evaluation corpus and scorer (partial)

Implements a deterministic set of **240 labeled synthetic source cases** across 12 categories with **140 adversarial/ambiguous** tests (missing source, version switch, draft-as-enacted, unsupported predictions, personal legal advice, hostile questions, and source-instruction attacks). Cases are pinned to synthetic text and SHA-256 quotes. The 48 held-out cases are split mechanically and must not be used for prompt/model tuning; their deterministic nature does not make them statistically independent real-world questions.

A standalone scorer requires model/prompt/validator/retrieval/corpus fingerprints, tests version, evidence IDs, decisive exception inclusion, status mistakes and legal safety flags, and reports held-out versus development results. Running the corpus **without actual model outputs reports zero executed tests, not an invented 100% score.** Reference predictions provided in unit tests are synthetic fixtures solely to demonstrate scoring correctness.

Remaining AB-040 acceptance: 240 independently curated/annotated real source-grounded cases (including 80 adversarial), real held-out evaluation run with a configured provider, substantive claim support/recall metrics, human-checked source judgments, cost/latency, and failure remediation. No character asset or unrelated product integration is required to develop this harness.
