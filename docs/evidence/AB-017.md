# AB-017 — legislative XML parser / namespace and hierarchy

Built a network-free typed hierarchy reader for a conservative federal USLM-like XML subset, preserving original identifiers and exact textual content, stable parent/child paths, version IDs, SHA-256 digests, label and heading. It reports unsupported tags rather than fabricating semantics and refuses entities, DTDs, invalid XML, duplicate IDs and overdepth documents. Every output remains an incomplete, nonpublishable preview.

Verification: node --test tests/xml.test.mjs and head-bound CI. True official bill sample comparison, namespaces/footnotes and release-level exactness remain open before final operational acceptance. Rollback: suppress structured XML previews and retain the authoritative raw source document.
