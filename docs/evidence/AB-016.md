# AB-016 — bounded Poppler PDF and OCR preview

This feature is a **quarantine-only** candidate implementation. It extracts native text for a bounded number of pages, detects empty/scan pages, generates private PNG review thumbnails with SHA-256 digests, and supports opt-in OCR with confidence warnings. Pages not processed, blank pages, OCR and non-native text are review blockers; extracted previews never become published source automatically.

The worker adapter sanitizes child environment, passes fixed Poppler arguments without shell execution, enforces tool output/timeout limits, uses a private scratch directory and deletes it afterward. The Docker runner uses network denial, non-root, read-only filesystem and CPU/memory/PID limits. A review-only CLI intentionally does not log private page text. Production parser hardening and source-page comparison remain pending.

Verification: run node --test tests/pdf.test.mjs on a host with Poppler or the dedicated GitHub PDF job (which installs the binaries); confirm exact-head quality, browser, database and PDF jobs. Browser/React correction tooling and actual source-authoritative approval are not yet implemented. Rollback: disable the PDF adapter, preserve immutable originals and quarantine pending documents.
