# AB-018 — version-specific Unicode anchors and source quote spans

Implements SHA-256 version+provision+canonical-text anchors, exact quote occurrence and digest checks, ambiguity rejection and code-point/UTF-16 conversion without splitting surrogate pairs. Includes deterministic property-based Unicode regression tests (emoji, combining forms, ligatures, CRLF, random sequences) and wrong-version/quote/locator tampering cases.

All original text is retained without implicit normalization; this supports future exact DOM highlighting and citations but does not yet implement the full client/DOM navigation UI. Test under Node 24 and exact-head GitHub CI; review that invalid or cross-version spans cannot be accepted. Rollback: disable derived anchors; original source/version IDs remain immutable.
