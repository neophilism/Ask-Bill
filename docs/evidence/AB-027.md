# AB-027 Immutable extraction corrections — partial

An authorized owner/editor with recent MFA and a fresh publisher membership decision can propose a character-level extraction correction against a source record whose SHA-256 is independently verified. A correction **never mutates the original source, old published version or raw bytes**; it creates a new private incomplete version requiring review, reindexes/re-evaluates derived claims before any publication, and produces a privacy-minimal audit descriptor with old/new hashes and actor/version IDs rather than personal source text. Unicode offsets prevent surrogate pair drift.

The old version remains pinned to existing sessions; new private text is never silently presented to public readers. Cross-publisher changes, fake MFA, altered source digests, no-ops and source quote mismatches are rejected. Four focused tests cover the foundation.

Remaining acceptance: trusted authenticated admin API, permanent PostgreSQL append-only correction/audit ledger, full-version canonical re-extraction, publisher review interface, index/tour and correction invalidation jobs, staged publication/rollback. Boolean trusted-MFA flags are placeholders for a real server-side authorization gate, not authorization from a browser. This PR is not a live editor.
