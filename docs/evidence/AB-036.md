# AB-036: source-verified accessible citations — partial

The text-only answer viewer now validates ordered `AnswerEvent` envelopes with `AnswerStreamGuard`, verifies every displayed source text digest and exact Unicode quote hash against independently supplied, complete, published versioned content. Only exact bill-text quotations are renderable until independently reviewed semantic claims are supported. A user-set `approved: true` field never authorizes display. Source cards escape active markup and point back to deterministic provision IDs. Four unit/adversarial tests cover tampered citations, missing source, version mismatch, forged answer events and markup injection.

**Acceptance remaining:** browser/React source drawer integration, keyboard and screen-reader journeys, trusted source-pack transport, server-issued authorization for publication, accessible correction flows, and real HTTP tests. No live chat or voice is enabled by this component. Ask Bill remains separate from all unrelated services.
