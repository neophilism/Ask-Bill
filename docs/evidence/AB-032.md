# AB-032 — exact source-span claim gate, before any answer is shown

The AB-032 validator receives an explicitly untrusted provider draft plus tenant/publisher-pinned AB-031 evidence. It refuses wrong document versions, private sources, unsupported current-law or prediction claim kinds, fabricated source IDs, tampered UTF-8 digests, arbitrary citation metadata and ambiguous repeated quotes. The validator builds spans itself from byte-verified original Unicode source, then invokes the existing shared @ask-bill/contracts runtime verifier. It produces structured claim IDs and separate provenance hashes.

Every successful result has `displayAllowed: false`, `spokenAllowed: false`, `semanticEntailmentVerified: false`, and `status: awaiting_semantic_review`; even a correctly cited quote cannot prove the claim's legal interpretation. Exceptions and unresolved sources remain explicit review flags for AB-033. No model-generated citation/URL/DOM selector becomes authoritative and no live AI is exposed.

Tests: exact quote and emoji boundaries, fabricated quote IDs, forged publisher/version, unpaired evidence hashes, duplicate occurrences, unsupported current-law predictions, fabricated "enacted" claims, unknown answers and child/private input denial. Run pinned workspace quality + Chromium/PostgreSQL/PDF CI against the exact head.

Missing acceptance: semantic entailment, exception-completeness evaluations, live-provider staging and actual answer/citation UI remain subsequent units; these must pass before the result is user-visible. Rollback: withhold all generated answer segments and serve exact source text only.
