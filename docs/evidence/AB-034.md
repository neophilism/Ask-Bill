# AB-034: Anonymous sessions and usage ledger (partial)
The implementation adds short-lived random capabilities and a PostgreSQL-backed, tenant-scoped generation reservation ledger. SQL rows are locked to serialize reservation admission, prevent same-key duplicate charges, and settle or release idempotently. Generation defaults disabled; public reading does not require these quotas.
