# AB-038 Hostile source and prompt-injection defenses — implementation checkpoint

The boundary serializes server-authorized version-pinned source text as quoted JSON *data*, never as system instructions, and never exposes model tool execution. Only server-initiated allowlisted read operations on the selected published version can be authorized. Every included provision requires a correct hash, tenant/version scope and inclusion of decisive exception sources. Untrusted provider output permits no tool calls or active markup; it is held for the independent citation/semantic review gate (AB-032/033). Display uses escaped plain text, not markdown execution.

Adversarial fixtures test instruction-looking bill text, forged assistant roles, malicious HTML, unsafe URLs, source-hash changes, cross-publisher records, omitted exceptions and unauthorized tools. The defensive policy does not rely on keyword-blocking every hostile sentence, which could erroneously suppress quoted law.
