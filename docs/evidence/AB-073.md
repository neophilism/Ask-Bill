# AB-073 — Mobile stage geometry and safe docking (partial)

Depends on AB-004, AB-066, AB-067, AB-071, AB-072 and AB-075. This work adds a pure, bounded mobile stage policy under `packages/character/mobile/stage.mjs`, consuming already-validated browser layout measurements. The display policy never scrolls the page, controls focus, obscures source text, or trusts an LLM for coordinates.

Supports measured visual viewport/safe-area insets, keyboard and selection/focus collisions, reserved dock, alternate registered whitespace target, version/layout revision fencing, reduced motion, paused/hidden controls and source-first fallback to stationary dock/hidden. It explicitly does **not** animate arbitrary cross-page travel or claim a final renderer integration; a future path graph must verify each path.

Local `node --check packages/character/mobile/stage.mjs && node --test tests/mobile-stage.test.mjs` run with Node v22.16.0: 10 independent regression and adversarial tests passed after validating the pure-policy paths. Live Playwright mobile physical browser and renderer tests are not yet verified; exact-head CI is required before merge and operational acceptance remains open. The final Bill GLB is still owner-pending.

Rollback: revert this policy; retain source-only reader, manually controlled character dock, and paused/hide alternatives.
